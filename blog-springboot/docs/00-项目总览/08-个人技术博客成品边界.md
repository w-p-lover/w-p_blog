# 个人技术博客成品边界

2026-11-26 用户明确将项目收拢为个人技术博客。此决定替代此前“持续新增业务/AI/活动”的开发方向；旧实现的存在不构成继续维护的理由。

## 当前产品

作者写作、保存草稿、发布/修改/撤回文章；读者浏览、检索、按分类/标签/归档查找内容，通过评论交流。保留说说（含配图、图片预览、点赞和评论）、关于、友链、账号与必要后台。首页保留照片轮播、一言、推荐阅读和文章流；桌面宠物及按既有站点设置启用的音乐播放器作为个人风格保留。不承载工具合集和 AI 浮窗。

核心后台保留文章/分类/标签、说说发布/编辑/图片上传、评论/留言管理、账号/角色/菜单、上传文件、站点配置和必要日志/调度。历史留言数据及后台管理保留，独立弹幕留言页退出前台。文章缓存、读取可见性、搜索同步和邮件通知继续服务现有业务。

业务精简与视觉精简分开：配色、背景、波浪、过渡、悬停、文章/评论点赞与回复等原有体验保留；不能因功能数量精简而一并删除。音乐播放器只需要旧的站点歌单配置，不恢复整套音乐库 CRUD。

移出当前版本：独立 AI 问答/写作/摘要向量流水线、活动报名、聊天/协作文档、音乐库、书架、天气、游戏、路线、榜单和相册，以及对应页面/API/consumer/mapper/专用配置。Spring AI、Qdrant、WebSocket 与专用前端依赖退出默认依赖。没有为每项历史功能增加开关。

## 后续开发标准

先解决真实写作、阅读、发布和部署中的问题。只有实际使用出现需要，才讨论新增业务或恢复模块；不以每天有提交、技术名词数量或已有投入作为开发依据。已有故障/并发证据保留其原始范围，不把过去的报名/AI 验证写成当前产品能力。

本地构建、受控 API 页面检查与真实依赖联调分开记录。当前阶段不自动合并、推送、部署，不执行历史迁移。
