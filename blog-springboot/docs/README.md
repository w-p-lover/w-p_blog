本目录用于集中管理 `blog-springboot` 的项目文档。当前文档不再只按“架构 / 运维 / 缓存”粗分，而是按实际阅读场景拆分为项目总览、架构设计、阶段计划、阶段总结、缓存体系、AI 体系、部署运维、数据库变更、前端接入、模板脚本和开发过程记录。

如果你只是想快速了解项目价值，先读 `00-项目总览`。如果你想看某个阶段开发前怎么设计，读 `02-阶段计划`。如果你想看某个阶段最终改了什么，读 `03-阶段总结`。

## 目录使用规则

- `00-项目总览`：项目定位、就业价值、长期发展路线。
- `01-架构设计`：跨模块、长期有效的整体架构设计。
- `02-阶段计划`：某个开发阶段开始前的实施计划。
- `03-阶段总结`：某个开发阶段完成后的交付总结。
- `04-缓存体系`：Redis、多级缓存、热榜、预热、限流、缓存治理。
- `05-AI体系`：AI 能力地图、RAG、任务中心、Prompt、模型治理。
- `06-部署运维`：本地启动、环境配置、部署、验收命令、配置中心。
- `07-数据库变更`：建表 SQL、权限 SQL、字段变更、迁移说明。
- `08-前端接入`：前端页面、交互、接口接入计划。
- `09-模板与脚本`：本地模板、环境变量脚本、辅助脚本。
- `90-开发过程`：开发过程计划、临时执行计划和可追溯记录。
- `99-归档记录`：不再维护但需要保留历史的文档。

详细维护规范见 [04-文档体系维护规范](00-项目总览/04-文档体系维护规范.md)。

## 09-模板与脚本

适合存放不会进入业务代码、但对本地开发和部署有帮助的模板脚本。

- [local-secrets-template.ps1](09-模板与脚本/local-secrets-template.ps1)
- [verify_registration_sql.py](09-模板与脚本/verify_registration_sql.py)：新报名实际条件SQL的临时SQLite容量/回滚边界验证，不替代MySQL。
- [verify_registration_dependencies.py](09-模板与脚本/verify_registration_dependencies.py)：显式隔离依赖验收；--http只运行报名真实HTTP/MySQL/MQ/Redis/角色与日志切片，合成数据，资源清理读回。
- [verify_ai_task_sql.py](09-模板与脚本/verify_ai_task_sql.py)：实际mapper语句的临时SQLite并发验证，不连接业务库，不替代MySQL联调。
- [replay_article_search.py](09-模板与脚本/replay_article_search.py)：文章搜索故障的实际一次性恢复客户端，默认只计数，明确目标/execute后确认发布才发送源ACK；用法与限制见运维05。
- [verify_search_replay.py](09-模板与脚本/verify_search_replay.py)：新vhost中的实际搜索重试/转存/CLI及ACK间隙验收，ES边界受控；10月29日真实入口连接超时未执行整链。
- [test_replay_article_search.py](09-模板与脚本/test_replay_article_search.py)：客户端直接相关的离线数据保留边界验证。
- [verify_queue_dependencies.py](09-模板与脚本/verify_queue_dependencies.py)：显式执行/主机开关的独立schema/vhost/集合验证；可选`--java`运行真实任务事务/投递/专用消费链路，不启动全应用或模型。
