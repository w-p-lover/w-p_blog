# 文档目录

本目录用于集中管理 `blog-springboot` 的项目文档。当前文档按阅读场景合并为四类：项目总览、架构设计、部署运维、缓存体系。

## 命名规范

- 目录使用两位序号 + 中文分类名，例如 `00-项目总览`。
- 文档使用两位序号 + 中文语义名，例如 `01-就业项目分析.md`。
- 阶段文档统一使用 `PhaseN-主题`，不在文件名里混用日期。
- 技术专有名词可保留英文，例如 `Docker-Compose`、`Nacos`、`AI`。
- 模板脚本不参与序号排序，使用清晰中文名，例如 `本地密钥环境变量模板.ps1`。
- 新增文档优先放入现有分类；缓存、限流、热榜、预热、缓存治理相关内容统一放入 `03-缓存体系`。
- 只有确实不再维护、仅供追溯的文档才放入 `99-归档记录`。
