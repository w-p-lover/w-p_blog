# AI问答初始版前端接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `shoka-blog` 中新增独立的 `/ai-chat` 页面，接入已有后端 `/api/ai/chat` 接口，实现问题提交、回答展示、来源展示和基础加载/错误交互。

**Architecture:** 采用最小增量方案：新增独立 API 模块（`src/api/ai`）和独立页面（`src/views/AiChat/index.vue`），通过现有 `request.ts` 发送请求，沿用现有全局拦截器提示。路由与导航仅增加入口，不改动现有 `/chat` 业务逻辑，确保功能隔离与回归风险最小。

**Tech Stack:** Vue 3 + TypeScript + Vue Router 4 + Axios（`src/utils/request.ts`）+ Element Plus

- [ ] **Step 3: 写最小可用页面实现（script + template）**

将 `D:/IdeaProjects/blog/shoka-blog/src/views/AiChat/index.vue` 完整实现为：

```vue
<template>
  <div class="page-header">
    <h1 class="page-title">AI问答</h1>
    <img class="page-cover" src="@/assets/images/bg.jpg" alt="" />
  </div>

  <div class="bg">
    <div class="ai-card card">
      <el-input
        v-model="question"
        type="textarea"
        :rows="4"
        maxlength="500"
        show-word-limit
        placeholder="请输入你的问题，例如：Redis缓存击穿怎么解决？"
      />

      <div class="actions">
        <el-button type="primary" :loading="submitting" @click="handleSubmit">
          提问
        </el-button>
        <el-button :disabled="submitting" @click="handleClear">清空</el-button>
      </div>

      <div v-if="answer" class="answer-block">
        <h3>回答</h3>
        <p class="answer-text">{{ answer }}</p>
      </div>

      <div v-if="sources.length" class="sources-block">
        <h3>参考来源</h3>
        <ul>
          <li v-for="(item, idx) in sources" :key="`${item.url}-${idx}`">
            <a :href="item.url" target="_blank" rel="noopener noreferrer">
              {{ item.title || item.url }}
            </a>
          </li>
        </ul>
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { aiChat } from "@/api/ai";
import type { AiSource } from "@/api/ai/types";
import { ref } from "vue";

const question = ref("");
const submitting = ref(false);
const answer = ref("");
const sources = ref<AiSource[]>([]);

const handleSubmit = async () => {
  const content = question.value.trim();
  if (!content) {
    window.$message?.warning("请输入问题");
    return;
  }

  submitting.value = true;
  try {
    const { data } = await aiChat({ question: content });
    answer.value = data?.data?.answer || "";
    sources.value = data?.data?.sources || [];
  } finally {
    submitting.value = false;
  }
};

const handleClear = () => {
  question.value = "";
  answer.value = "";
  sources.value = [];
};
</script>
```
