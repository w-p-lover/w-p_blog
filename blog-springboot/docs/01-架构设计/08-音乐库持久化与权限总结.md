# 音乐库持久化后端支持阶段总结

## 升级内容

- 为最新前端音乐库模型补充 Spring Boot 后端持久化能力。
- 支持音乐库查询、手动保存、更新、删除、网易云歌单导入与重置。
- 音乐库浏览接口公开可访问，导入、新增、编辑、删除、重置接口要求登录并具备对应权限码。
- 提供 `t_music_playlist`、`t_music_item` 建表 SQL，字段贴合前端 `MusicPlaylist` 和 `MusicItem`。

## 注意事项

- 仓库当前没有统一迁移框架，本次只提供 SQL 文件，需要部署前手动执行。
- 执行 SQL 后，还需要在后台把新增音乐库权限分配给允许维护音乐库的角色；未分配权限的账号只能浏览，不能导入或编辑。
- 前端当前仍使用 `localStorage`，后续需要接入这些接口完成前后端联调。
- Meting 是外部公开接口，导入失败会返回可读错误；已保存的本地音乐库数据不依赖外部接口展示。
