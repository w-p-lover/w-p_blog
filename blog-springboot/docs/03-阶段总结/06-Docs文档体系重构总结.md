# Docs文档体系重构总结

## 本次目标

本次调整针对 `docs` 目录分类粗、阶段命名混乱、计划与总结混放、SQL 与部署说明混放的问题进行整理。目标不是重写所有文档内容，而是先建立稳定的信息架构，让后续阶段开发、复盘、面试展示和运维查阅都有固定入口。

本次根据你的要求没有切新分支，直接在当前 `wyp` 分支整理文档。

## 升级内容

- 将原本混在 `01-架构设计` 中的阶段计划、阶段总结、前端接入文档拆分到独立目录。
- 将原本混在 `02-部署运维` 中的 SQL 文件拆分到 `07-数据库变更`。
- 将缓存专题目录从旧的 `03-缓存体系` 调整为新的 `04-缓存体系`，为 `03-阶段总结` 留出固定位置。
- 新增 `05-AI体系`，作为 AI 任务中心、RAG、Prompt、模型治理等专题文档入口。
- 新增 `09-模板与脚本`，用于存放本地环境变量模板脚本。
- 新增 `90-开发过程`，用于保留较长的临时执行计划。
- 重写 `docs/README.md`，让它成为完整文档导航首页。
- 新增文档体系维护规范，约束后续新增文档的分类和命名。
- 更新已发现的旧路径引用，减少文档移动后链接失效的问题。
