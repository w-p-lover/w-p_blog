# 音乐库后端对接阶段总结

## 升级内容

- 将音乐库前端从纯 `localStorage` 数据持久化调整为后端接口持久化。
- 保留筛选、排序、当前选中歌曲等轻量 UI 状态在本地，歌曲和歌单主数据以服务端为准。
- 增加后端返回字段适配，兼容后端 `updateTime` 与前端 `updatedAt` 的命名差异。
- 写操作增加登录和权限体验层拦截：未登录提示先登录，登录但无音乐库维护权限提示无权限。

## 变更文件

- `src/api/music/index.ts`
  - 新增音乐库查询、手动保存、更新、删除、网易云导入、重置接口封装。
- `src/store/modules/music.ts`
  - 新增 `fetchLibrary`、`replaceLibrary`。
  - 将手动收藏、详情编辑保存、网易云歌单导入、重置切换为调用后端接口。
  - 持久化范围缩小为 `activeItemId`、`filter`、`sortType`，避免服务端主数据继续被本地覆盖。
  - 写操作调用前检查 token 和用户权限，避免无权限用户发起无意义请求。
- `src/store/modules/user.ts`
  - 保存后端返回的 `permissionList`，提供 `hasPermission` getter。
- `src/store/types/index.ts`
  - 为用户状态增加 `permissionList`。
- `src/api/login/types.ts`
  - 为登录用户信息增加 `permissionList`。
- `src/views/Music/musicModel.ts`
  - 新增 `normalizeMusicLibraryPayload` 和 `normalizeMusicItemPayload`，统一适配后端数据。
- `src/views/Music/musicModel.test.mjs`
  - 增加后端音乐库载荷适配测试。
- `src/views/Music/index.vue`
  - 首次进入页面拉取后端音乐库。
  - 手动收藏等待后端保存结果后再更新界面。
- `src/views/Music/MusicDetail.vue`
  - 首次进入详情拉取后端音乐库。
  - 编辑保存等待后端更新结果后再提示成功。

## 注意事项

- 后端接口默认走现有请求基地址 `http://localhost:8080`。
- 首次部署前需要执行后端新增的音乐库建表 SQL。
- 需要给允许维护音乐库的角色分配 `music:library:import`、`music:item:add`、`music:item:update`、`music:item:delete`、`music:library:reset` 权限。
- 前端构建仍有项目既有的 CSS nesting 和 chunk size 警告，本次改动没有新增阻断性构建错误。
