# 音乐库歌曲展示阶段总结

## 升级内容

- 将音乐库展示重心从“歌单陈列”调整为“歌曲收藏”。
- 保留站点通用 `page-header`、`page-title`、`page-cover` 和 `Waves` 标题结构。
- 支持从一个或多个网易云公开歌单批量导入歌曲。
- 首页收敛为歌曲封面墙与少量筛选入口，歌曲详情独立为 `/music/:id` 页面。
- 在歌曲详情页增加歌词展示，优先读取 Meting 返回的歌词链接。

## 文件变更

- `src/views/Music/index.vue`
  - 增加来源歌单横向卡片，每个卡片直接展示歌单内歌曲数量和歌曲预览。
  - 移除首页大详情与歌词模块，点击歌曲进入详情页。
  - 导入弹窗改为多行输入，支持一次粘贴多个歌单链接或 ID。

- `src/views/Music/MusicDetail.vue`
  - 新增歌曲详情页，展示封面、歌名、歌手、收藏备注、来源与歌词。
  - 保留编辑收藏信息的入口。

- `src/views/Music/css/music.scss`
  - 增加来源歌单卡片、歌曲封面墙、详情页和歌词区域样式。
  - 保持音乐库页面样式局部化，不修改全局通用样式。

- `src/router/index.ts`
  - 增加 `/music/:id` 歌曲详情路由。

- `src/views/Music/musicModel.ts`
  - 移除旧的虚拟示例歌曲数据，改为默认从网易云歌单导入。
  - 增加多歌单输入拆分与歌词解析工具函数。

- `src/store/modules/music.ts`
  - 增加默认歌单自动导入逻辑。
  - 增加多歌单批量导入 action。
  - 兼容旧的 `seed-` 演示数据，进入页面时会清理并导入真实歌曲。

- `src/views/Music/musicModel.test.mjs`
  - 用本地 fixture 替换对旧 seed 数据的依赖。
  - 覆盖歌单 ID 提取、多歌单拆分、歌词解析、筛选、统计和排序。

## 注意事项

- 歌词展示依赖 Meting 返回的 `lrc` 链接；如果第三方接口无歌词、跨域失败或网络失败，页面会显示暂无或读取失败。
- 默认导入使用当前站点播放器同一个网易云歌单 ID：`7573319758`。
